## Quick Start

### Option 1: Frontend Generates HTML (Recommended)

Frontend generates HTML and sends to backend API:

```python
# Backend receives HTML from frontend
POST /api/admin/send-email/
{
  "to": "user@example.com",
  "subject": "Welcome to RentalConnects",
  "html": "<!DOCTYPE html>...",  # Generated by frontend
  "text": "Plain text version"   # Optional
}
```

**Backend Implementation:**
```python
# Django example
@api_view(['POST'])
@permission_classes([IsAdminUser])
def send_email(request):
    to = request.data.get('to')
    subject = request.data.get('subject')
    html = request.data.get('html')
    text = request.data.get('text', strip_html(html))
    
    send_mail(
        subject=subject,
        message=text,
        from_email=settings.DEFAULT_FROM_EMAIL,
        recipient_list=[to],
        html_message=html,
    )
    
    return Response({'success': True, 'sent_to': to})
```

## Backend Helper Function

### Python/Django Example

```python
# utils/email_templates.py
from django.conf import settings
from django.utils.html import strip_tags

EMAIL_COLORS = {
    'primary': '#0b6e4f',
    'primary_light': '#0d8a66',
    'primary_dark': '#095c42',
    'white': '#ffffff',
    'gray': '#6b7280',
    'gray_light': '#f3f4f6',
    'text': '#111827',
    'text_light': '#6b7280',
}

def render_email_template(
    title,
    content,
    button_text=None,
    button_url=None,
    preheader=None,
    logo_url=None
):
    """
    Generate complete HTML email template.
    
    Args:
        title: Email title/heading
        content: Main email content (HTML)
        button_text: Optional CTA button text
        button_url: Optional CTA button URL
        preheader: Optional preheader text (email preview)
        logo_url: Optional logo URL (defaults to settings.EMAIL_LOGO_URL)
    """
    from datetime import datetime
    
    # Get logo URL
    logo = logo_url or getattr(settings, 'EMAIL_LOGO_URL', None) or f"{settings.APP_URL}/logo.png"
    
    # Preheader HTML
    preheader_html = ""
    if preheader:
        preheader_html = f"""
        <div style="display: none; font-size: 1px; color: {EMAIL_COLORS['white']}; line-height: 1px; font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif; max-height: 0px; max-width: 0px; opacity: 0; overflow: hidden;">
          {preheader}
        </div>
        """
    
    # Button HTML
    button_html = ""
    if button_text and button_url:
        button_html = f"""
        <table width="100%" cellpadding="0" cellspacing="0" border="0" style="margin: 30px 0;">
          <tr>
            <td style="text-align: center;">
              <a href="{button_url}" style="display: inline-block; padding: 14px 32px; background-color: {EMAIL_COLORS['primary']}; color: {EMAIL_COLORS['white']}; text-decoration: none; border-radius: 6px; font-weight: 600; font-size: 16px; font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;">
                {button_text}
              </a>
            </td>
          </tr>
        </table>
        """
    
    # Current year for copyright
    current_year = datetime.now().year
    
    return f"""
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta http-equiv="X-UA-Compatible" content="IE=edge">
  <title>{title}</title>
```

```python
try:
```

## Login Activity Email Notifications

### Overview

Send email notifications for login activities to enhance account security. Users are notified of:
- Successful logins
- Failed login attempts
- Logins from new devices
- Suspicious login activity

### Implementation

#### 1. Track Login Activity

**Required Data to Collect:**
- IP Address (`request.META.get('REMOTE_ADDR')`)
- User Agent / Device (`request.META.get('HTTP_USER_AGENT')`)
- Location (optional, from IP geolocation service)
- Timestamp
- Device fingerprint (optional)

**Example Django Implementation:**
```python
# utils/login_tracking.py
import ipaddress
from django.utils import timezone
from geopy.geocoders import Nominatim

def get_client_ip(request):
    """Get client IP address from request"""
    x_forwarded_for = request.META.get('HTTP_X_FORWARDED_FOR')
    if x_forwarded_for:
        ip = x_forwarded_for.split(',')[0]
    else:
        ip = request.META.get('REMOTE_ADDR')
    return ip

def get_device_info(request):
    """Extract device information from user agent"""
    user_agent = request.META.get('HTTP_USER_AGENT', '')
    # Parse user agent to get device/browser info
    # Use library like user-agents or ua-parser
    return {
        'device': user_agent,  # Or parsed device name
        'browser': 'Chrome',    # Parsed browser
        'os': 'Windows',        # Parsed OS
    }

def get_location_from_ip(ip_address):
    """Get location from IP address (optional)"""
    try:
        geolocator = Nominatim(user_agent="rentalconnects")
        location = geolocator.geocode(ip_address)
        return location.address if location else None
    except:
        return None
```

#### 3. Failed Login Attempt Email

**When to Send:**
- After failed login attempt (wrong password)
- Rate limit: Send max 1 email per 15 minutes per user

**Subject:** `Failed Login Attempt - RentalConnects Security Alert`

**Example:**

```python
def send_failed_login_notification(user, request):

    location = get_location_from_ip(ip_address)

        'loginTime': timezone.now().strftime('%B %d, %Y at %I:%M %p'),

        'device': f"{device_info.get('device', 'Unknown Device')}",
        'location': location or 'Unknown Location',
    }
    
    html = generate_failed_login_email(user, login_data)
    
    send_mail(
        subject='Failed Login Attempt - RentalConnects Security Alert',
        message=strip_tags(html),
        from_email=settings.DEFAULT_FROM_EMAIL,
        recipient_list=[user.email],
        html_message=html,
    )

# In login view
@api_view(['POST'])
def login_view(request):
    email = request.data.get('email')
    password = request.data.get('password')
    
    try:
        user = User.objects.get(email=email)
        if not user.check_password(password):
            # Failed login
            send_failed_login_notification.delay(user.id, request)
            return Response({'error': 'Invalid credentials'}, status=401)
    except User.DoesNotExist:
        # Don't reveal if user exists
        return Response({'error': 'Invalid credentials'}, status=401)
```

#### 5. Suspicious Login Activity Email

**When to Send:**
- Login from unusual location (different country)
- Multiple failed attempts from same IP
- Login from known malicious IP ranges
- Unusual login time patterns

**Subject:** `🚨 Suspicious Login Activity - RentalConnects Security Alert`

**Example:**
```python
def detect_suspicious_activity(user, request):
    """Detect and notify about suspicious login activity"""
    ip_address = get_client_ip(request)
    device_info = get_device_info(request)
    location = get_location_from_ip(ip_address)
    
    suspicious = False
    reason = None
    
    # Check 1: Unusual location
    last_login = LoginHistory.objects.filter(user=user).order_by('-created_at').first()
    if last_login and last_login.location != location:
        # Check if location is very far (different country)
        suspicious = True
        reason = f"Login from new location: {location}"
    
    # Check 2: Multiple failed attempts
    failed_attempts = FailedLoginAttempt.objects.filter(
        user=user,
        ip_address=ip_address,
        created_at__gte=timezone.now() - timedelta(minutes=15)
    ).count()
    if failed_attempts >= 3:
        suspicious = True
        reason = f"Multiple failed login attempts ({failed_attempts}) from this IP"
    
    # Check 3: Known malicious IP
    if is_malicious_ip(ip_address):
        suspicious = True
        reason = "Login attempt from known malicious IP address"
    
    if suspicious:
        login_data = {
            'loginTime': timezone.now().strftime('%B %d, %Y at %I:%M %p'),
            'ipAddress': ip_address,
            'device': f"{device_info.get('device', 'Unknown Device')}",
            'location': location or 'Unknown Location',
            'reason': reason,
        }
        
        html = generate_suspicious_login_email(user, login_data)
        send_mail(
            subject='🚨 Suspicious Login Activity - RentalConnects Security Alert',
            message=strip_tags(html),
            from_email=settings.DEFAULT_FROM_EMAIL,
            recipient_list=[user.email],
            html_message=html,
        )
```

### Best Practices

1. **Rate Limiting:** Don't spam users with notifications
   - Max 1 failed login email per 15 minutes
   - Max 1 new device email per device
   - Max 1 suspicious activity email per hour

2. **Async Sending:** Use Celery or similar for async email sending
   ```python
   @shared_task
   def send_login_notification_async(user_id, login_data):
       user = User.objects.get(id=user_id)
       send_login_notification(user, login_data)
   ```

3. **User Preferences:** Allow users to opt-out of login notifications
   ```python
   if user.email_notifications.login_activity:
       send_login_notification(user, login_data)
   ```

4. **Logging:** Log all login activities for audit trail
   ```python
   LoginHistory.objects.create(
       user=user,
       ip_address=ip_address,
       device=device_info,
       location=location,
       success=True,
   )
   ```
